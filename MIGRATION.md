# BRKTRK source migration

The public source baseline was exported from myldy20/BRKTRK at exact
engineering commit 98192b126cac367e31cf16ded7d02e5b95336150 (version 0.9.0).

This exported repository starts from one new root commit. Previous private
commits, branches, tags, deployment records, the former private-repository
snapshots and archived engineering documents were deliberately excluded.

Earlier distribution copies retain the licenses that accompanied them.
The new BRKTRK host source is GPL-3.0-only; independent sound engines and
third-party material keep their own copyright and licensing obligations.
See NOTICE.md for current attributions.

Do not push old refs, tags or --mirror from the private engineering clone.
