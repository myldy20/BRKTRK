Keyboard map

ArrowsMove inside the current Song, Chain or Phrase grid S + ←/→Change the current value by a small step S + ↑/↓Change the current value by a large semantic step Z + →Open the selected Chain, Phrase or Sound context Z + ←Return to the exact parent cell Z + ↓ / ↑Open Mix / return from Mix SInsert/edit; double Edit allocates a fresh Chain or Phrase A + SClear/reset; on an empty Note insert Note Off A + arrowsChange Track or structural context XPlay/stop the selected Song, Chain or Phrase scope Z + XContinue or queue Song from the selected position Ctrl/Cmd + EnterInsert blank Phrase row(s), shifting down and truncating at 0F Ctrl/Cmd + BackspaceDelete selected/current Phrase row(s), shifting up Ctrl/Cmd + DDuplicate selected/current Song, Chain or Phrase row(s) directly below

On desktop, PLAY: AUTO follows the active Song, Chain or Phrase editor; choosing SONG, CHAIN or PHRASE fixes what Play starts for the current session. FOLLOW PLAYBACK lets the editor move with playback. FOLLOW PAUSED means manual browsing has temporarily paused following; press it to resume. Turn FOLLOW PLAYBACK off when you want the editor to stay where you put it.

On phone, tap a Note once to select it and tap the selected Note again—or use EDIT NOTE—to open the chromatic Note Editor.
